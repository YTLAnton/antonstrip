# 行程表編輯教學

這份行程表的設計非常方便，所有的資料都集中在**每個行程資料夾下的 `itinerary.md`**，例如：
```
2026_05_Singapore/
  ├── index.html      ← 介面/邏輯，不用動
  ├── itinerary.md    ← 你只需要編輯這個檔案
  └── img/
```
你**完全不需要修改任何 HTML、CSS 或 JavaScript 程式碼**，只需要像寫筆記一樣編輯 `itinerary.md` 裡的純文字即可。

> 📌 **舊版相容**：尚未拆出 `itinerary.md` 的資料夾（例如部分早期行程），資料仍嵌在 `index.html` 中段 `<script id="trip-data" type="text/plain">` 區塊內，編輯語法跟下方教學完全相同，只是改的檔案不一樣。
>
> ⚠️ **本機開啟方式**：拆出 `itinerary.md` 之後不能再用瀏覽器雙擊 `index.html` 來看（會被瀏覽器擋 `fetch`）。預覽請：
> - 推上 GitHub 後用 GitHub Pages 網址開啟，或
> - 在資料夾內跑 `python -m http.server 8000`，瀏覽器開 `http://localhost:8000/`

行程表主要分為 **5個大區塊**（基本設定、每日行程、美食清單、航班資訊、行李/須知），以下為各區塊的編輯與增減教學：

---

## 1. 基本設定 (最上方的 YAML 區塊)
在 `---` 與 `---` 包住的範圍內，控制了首頁和 App 的基本屬性。
> ⚠️ **注意**：冒號 `:` 後面請務必保留「**一個半形空格**」。

```yaml
---
title: "新加坡 2026"
emoji: "🇸🇬"
subtitle: "2026/05/01 - 05/03 (3天2夜)"
people: 4
tripType: "自由行"

# 這裡可以自由增減交通方式
transport: ["MRT", "Grab", "步行", "包車"] 

weather:
  新加坡:
    temp: "28-34°C"
    condition: "熱帶氣候，全年高溫潮濕"
    tips: "防曬、補水、隨身帶雨傘"
    url: "https://www.weather.gov.sg/"
---
```

## 2. 編輯「每日行程」
每一天的行程都使用 `## Day X` 作為標題開頭。

### ✔️ 新增一天
複製或輸入以下格式來建立新的一天：
```markdown
## Day 1 | 2026/05/01 (五) | 標題名稱 (例如：抵達新加坡)

route: 台北 → 新加坡  
dayNote: 這裡寫該日的重要備註、提醒事項\n第二行用 \n 換行\n第三行
```

### ✔️ Day 0：行前準備清單
在第一天之前可以加入 Day 0，專門用來放出發前的待辦事項。Day 0 有兩種格式，日期為選填：

```markdown
## Day 0 | 行前準備          ← 不放日期（推薦）
## Day 0 | 2026/04/10 (五) | 行前準備  ← 放日期（開啟時若今天是此日期，會自動定位）
```

Day 0 的活動會自動渲染成**可勾選的分類清單**（勾選狀態儲存在瀏覽器，重新整理不會消失）。

---

#### 格式一：單人（不顯示頁籤）
使用 `### 分類 | 名稱` 直接列出：

```markdown
## Day 0 | 行前準備

dayNote: 出發前請確認以下事項皆已完成\n護照效期需 6 個月以上

### 文件 | 護照（確認效期）
### 文件 | 國際駕照
### 清潔 | 牙刷、牙膏
### 電子 | 充電器
### 電子 | 行動電源（≤100Wh，放手提）
```

---

#### 格式二：多人（自動顯示人名頁籤）
先用 `### 人名`（**不加 `|`**）建立人名區塊，然後在下面用 `- 分類 | 項目` 列出該人的物品。  
屬於所有人的共用項目仍沿用 `### 分類 | 名稱` 格式，會顯示在所有頁籤下方的「共用」區塊。

> ⚠️ 人名區塊的 `###` 後面**不能有 `|`**，否則會被判斷為一般活動項目。

```markdown
## Day 0 | 行前準備

dayNote: 出發前請確認以下事項皆已完成

### Anton
- 👕 衣物 | 短袖上衣 x 3
- 👕 衣物 | 內褲 x 3
- 🔌 電子 | iPhone 15 Pro Max
- 🔌 電子 | 行動電源 * 2
- 💊 藥妝 | Loxonin * 3

### Horlick
- 👕 衣物 | 短袖上衣 x 3
- 🔌 電子 | 手機充電器
- 💊 藥妝 | 暈車藥

### 🛂 證件 | 護照
### 🛂 證件 | 台胞證
### 💳 重要 | 星展卡
### 💳 重要 | 現金 SGD 1,000
```

**顯示效果：**
- 有 2 個以上人名 → 頂部出現人名頁籤（`Anton` / `Horlick`），切換頁籤只顯示該人的物品
- 只有 1 個人名 → 不顯示頁籤，直接列出所有項目
- `### 分類 | 名稱` 的共用項目 → 固定顯示在頁籤下方「共用」區塊

> 💡 分類名稱（`衣物`、`電子`、`藥妝`…）可以自由命名，前面可加 emoji，同分類的項目會自動歸為同一群組。

### ✔️ 新增單一活動
每個活動都是以 `### 分類 | 名稱` 開頭。如果不想要某個欄位，**直接將該行刪除即可**。
系統支援的分類有：`行程` 🎯、`景點` 📸、`飲食` 🍽️、`交通` 🚗、`任務 📋、`住宿` 🏠、`參考` 💡、`休息` 😴、`展覽` 🖼️、`購物` 🛍️。

**標準活動格式與所有可用欄位：**
```markdown
### 景點 | 濱海灣花園

time: 15:00
# 【必填】開始時間，格式為 HH:MM（24 小時制）

endTime: 18:30
# 【選填】結束時間，填入後會顯示為「15:00 - 18:30」

description: 新加坡地標，晚上有免費的超級樹光影秀。==光影秀免費入場==，~~需事先預約~~
# 【選填】活動描述。支援 ==螢光標記== 和 ~~刪除線~~ 標記語法

hours: 05:00-02:00（跨夜）
# 【選填】場所的實際營業時間（非活動時間）

cost: SGD 14 / 人
# 【選填】花費或預算，填入後會顯示為卡片右下角的標籤

ticket: 成人 SGD 14，小孩 SGD 8\n網路預購享 9 折，現場購票要排隊\n憑電子票入場即可
# 【選填】票務說明，橘色框顯示，用 \n 換行

meta: 光影秀每晚 19:45 & 20:45 各一場，建議提前 20 分鐘入場佔位
# 【選填】補充資訊，黃色框顯示，適合放場次時間、注意事項等

address: 18 Marina Gardens Dr, Singapore 018953
# 【選填】地址，填入後介面上會出現「👁 給司機看」按鈕（大字顯示給司機看）

mapLink: https://maps.app.goo.gl/ABC123
# 【選填】Google Maps 分享連結，出現「🗺 Google Maps」導航按鈕

notes: ⚠️ 如遇下雨光影秀會取消，請留意官網公告\n建議穿防蚊噴霧，晚上蚊子多
# 【選填】個人備註，灰底框顯示，用 \n 換行

copyable: BOOKING-REF-E2TSMJ
# 【選填】點擊後自動複製的文字，綠色框顯示，適合放訂位代碼、確認號碼

docLink: https://drive.google.com/file/d/xxxxx
# 【選填】顯示「🔗 相關連結」按鈕，在新分頁開啟，適合放 Google Doc、訂位 PDF、行前說明

app: Grab
# 【選填】顯示對應 App 的導轉按鈕，支援：台鐵、高鐵、長榮航空、國泰航空、Agoda、Grab

imageUrl: https://raw.githubusercontent.com/YTLAnton/antonstrip/main/2026_05_Singapore/img/garden.jpg
# 【選填】第一張圖片，點擊可放大（Lightbox）

imageUrl2: https://raw.githubusercontent.com/YTLAnton/antonstrip/main/2026_05_Singapore/img/garden2.jpg
# 【選填】第二張圖，與第一張並排顯示

imageUrl3: https://raw.githubusercontent.com/YTLAnton/antonstrip/main/2026_05_Singapore/img/garden3.jpg
# 【選填】第三張圖，三張時自動排列為「1大2小」版型

imageSize: small
# 【選填】單張圖片縮小顯示，預設為正常大小（適合截圖或示意圖）

cancelled: true
# 【取消功能】加上這行，此行程卡片會變灰色並畫刪除線

cancelReason: 行程太滿，改為自由活動
# 【取消備註】顯示在取消行程卡片的內部，說明取消原因

group: Anton, Horlick
# 【分組功能】相同 group 值的活動歸為同一欄，見下方說明
```

### ✔️ 分組行程（同時間、不同人馬各自行動）
當行程中有兩組人馬在同一時段做不同的事，在每個活動加上 `group:` 欄位，系統會自動依 **相同 `group:` 值歸為同一欄**，不同值並排顯示。每欄的活動由上到下排列，不會交叉混排。

```markdown
### 飲食 | 天天海南雞飯      ← 左欄第 1 行
time: 12:00
group: Anton, Horlick
cost: SGD 8/人
address: Maxwell Food Centre

### 景點 | 濱海灣花園        ← 左欄第 2 行
time: 14:00
group: Anton, Horlick

### 飲食 | 辣螃蟹            ← 右欄第 1 行
time: 12:00
group: Wendy, John
cost: SGD 80/2人
address: Jumbo Seafood

### 景點 | 聖淘沙            ← 右欄第 2 行
time: 14:00
group: Wendy, John

### 交通 | 返回酒店          ← 回到一般全寬顯示（沒有 group:）
time: 18:00
```

**顯示效果：**
```
⑂ 分組行程
┌──────────────────┬──────────────────┐
│ 👥 Anton, Horlick│ 👥 Wendy, John   │
├──────────────────┼──────────────────┤
│ [天天海南雞飯]    │ [辣螃蟹]          │
│ [濱海灣花園]      │ [聖淘沙]          │
└──────────────────┴──────────────────┘
[返回酒店]（全寬）
```

**規則：**
- **相同 `group:` 值** → 同一欄，由上到下排列
- **不同 `group:` 值** → 不同欄，左右並排
- 連續有 `group:` 的活動歸入同一個分組區塊；中間插入沒有 `group:` 的活動即自動切斷
- 三組人馬也支援（三個不同 `group:` 值 → 三欄並排）
- 所有既有欄位（`address`、`mapLink`、`cost`、`app` 等）在分組 card 內都正常運作

### ✔️ 住宿特殊格式
若是住宿分類（`### 住宿 | XXX`），可用以下專用欄位（自動呈現為可摺疊收納的面板）：

# 【選填】抵達或 check-in 時間，顯示在時間軸

price: SGD 450 / 晚
# 【選填】房價，展開後顯示為費用欄位

nights: 2
# 【選填】入住幾晚，展開後顯示為「2 晚」

ticket: Tower 1, 高層房，城市景觀\n確認 early check-in 是否可行
# 【選填】訂房相關票務說明，橘色框顯示，用 \n 換行

meta: 含早餐，餐廳在 B1\n泳池 06:00-22:00，需憑房卡進入
# 【選填】補充資訊，黃色框顯示，適合放設施說明、早餐時間

address: 10 Bayfront Ave, Singapore 018956
# 【選填】飯店地址，填入後出現「👁 給司機看」按鈕

mapLink: https://maps.app.goo.gl/ABC123
# 【選填】Google Maps 連結，出現「🗺 Google Maps」導航按鈕

notes: ⚠️ 退房前一晚確認 late check-out 是否可申請\n行李寄放可至大廳 concierge
# 【選填】個人備註，用 \n 換行

copyable: Booking ref: MBS-20260501-E2TSMJ
# 【選填】點擊即複製，適合放訂房確認碼

docLink: https://drive.google.com/file/d/xxxxx
# 【選填】訂房確認 PDF 或相關文件連結

app: Agoda
# 【選填】顯示 App 導轉按鈕，支援：Agoda、Grab 等

## 7. 新增活動圖片

### 圖片放在哪裡？
每個行程資料夾下都有一個 `img/` 子資料夾，圖片統一放這裡：
```
2026_04_HK/
  ├── index.html
  ├── itinerary.md
  └── img/
       ├── 普特曼酒店.jpg
       └── M+博物館.jpg
```
> 💡 **建議用英文或數字命名**，避免中文檔名在網址中變成亂碼（如 `%E6%99%AE...`）

---

### 取得圖片網址（兩種方式）

#### 方式一：自己組網址（最快）
只要知道檔名，照以下規律填入即可，**前綴永遠不變**：

```
https://raw.githubusercontent.com/YTLAnton/antonstrip/main/【資料夾名稱】/img/【檔名.jpg】
```

範例：
```
https://raw.githubusercontent.com/YTLAnton/antonstrip/main/2026_04_HK/img/Putman-Hotel.jpg
https://raw.githubusercontent.com/YTLAnton/antonstrip/main/2026_04_MO/img/grand-lisboa.jpg
```

#### 方式二：從 GitHub 網頁複製（最簡單）
1. 開啟 GitHub 網頁，進入 `img/` 資料夾，點進圖片檔案
2. 圖片出現後，在圖片上**按右鍵 → 「複製圖片網址」**（Chrome/Edge 皆支援）
3. 貼出來的網址長這樣，**可以直接使用**：
   ```
   https://github.com/YTLAnton/antonstrip/blob/main/2026_04_HK/img/Horlick(2025).JPG?raw=true
   ```
4. 注意：網址結尾必須有 `?raw=true`，如果貼出來沒有這個結尾（只有 `blob/main/...`），則無法顯示圖片

---

### 推上 GitHub 才會生效
圖片放進 `img/` 後，必須先推上 GitHub，網址才能存取：
```bash
git add .
git commit -m "add images"
git push
```
> ⚠️ 在推上去之前，用瀏覽器直接開啟 index.html 時圖片會顯示不出來，這是正常的。

## 💡 新手防呆小訣竅

1. **不想顯示的欄位**：不要留空，直接將該屬性**整行刪除**即可，系統會自動適應隱藏它。
2. **快速新增**：遇到想加行程時，最快的方法是**直接複製一段既有的** `### 景點 | XXX` 區塊，貼上後再修改裡面的文字，保證不出錯！
3. **格式錯誤檢查**：如果畫面突然怪怪的，先檢查你的冒號 `:` 後方是不是少打了一個「半形空格」（正確範例 `time: 15:00`）。
