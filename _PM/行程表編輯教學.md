# 行程表編輯教學 (index.html)

這份行程表的設計非常方便，所有的資料都集中在 `index.html` 檔案中的 `<script id="trip-data" type="text/plain">` 區塊內（大約在第 1250 行到 1447 行區間）。
你**完全不需要修改任何 HTML、CSS 或 JavaScript 程式碼**，只需要像寫筆記一樣編輯裡面的純文字即可。

行程表主要分為 **5個大區塊**（基本設定、每日行程、美食清單、航班資訊、行李/須知），以下為各區塊的編輯與增減教學：

---

## 1. 基本設定 (最上方的 YAML 區塊)
在 `---` 與 `---` 包住的範圍內，控制了首頁和 App 的基本屬性。
> ⚠️ **注意**：冒號 `:` 後面請務必保留「**一個半形空格**」。

```yaml
---
title: "新加坡 2026"
emoji: "🇸🇬"
subtitle: "2026/05/01 - 05/03 (3天2夜)"
people: 4
tripType: "自由行"

# 這裡可以自由增減交通方式
transport: ["MRT", "Grab", "步行", "包車"] 

weather:
  新加坡:
    temp: "28-34°C"
    condition: "熱帶氣候，全年高溫潮濕"
    tips: "防曬、補水、隨身帶雨傘"
    url: "https://www.weather.gov.sg/"
---
```

## 2. 編輯「每日行程」
每一天的行程都使用 `## Day X` 作為標題開頭。

### ✔️ 新增一天
複製或輸入以下格式來建立新的一天：
```markdown
## Day 1 | 2026/05/01 (五) | 標題名稱 (例如：抵達新加坡)

route: 台北 → 新加坡  
dayNote: 這裡寫該日的重要備註、提醒事項\n第二行用 \n 換行\n第三行
```

### ✔️ Day 0：行前準備清單
在第一天之前可以加入 Day 0，專門用來放出發前的待辦事項。Day 0 有兩種格式，日期為選填：

```markdown
## Day 0 | 行前準備          ← 不放日期（推薦）
## Day 0 | 2026/04/10 (五) | 行前準備  ← 放日期（開啟時若今天是此日期，會自動定位）
```

Day 0 的活動會自動渲染成**可勾選的分類清單**（勾選狀態儲存在瀏覽器，重新整理不會消失）。格式與一般活動相同，分類名稱即為清單的群組標題：

```markdown
## Day 0 | 行前準備

dayNote: 出發前請確認以下事項皆已完成\n護照效期需 6 個月以上

### 文件 | 護照（確認效期）
### 文件 | 國際駕照
### 文件 | 訂房確認信列印

### 清潔 | 牙刷、牙膏
### 清潔 | 毛巾
### 清潔 | 隱形眼鏡＋清潔液

### 電子 | 充電器
### 電子 | 行動電源（≤100Wh，放手提）
```

> 💡 分類名稱可以自由命名，不限於系統預設的行程、景點等類型。

### ✔️ 新增單一活動
每個活動都是以 `### 分類 | 名稱` 開頭。如果不想要某個欄位，**直接將該行刪除即可**。
系統支援的分類有：`行程` 🎯、`景點` 📸、`飲食` 🍽️、`交通` 🚗、`作業` 📋、`住宿` 🏠、`參考` 💡、`休息` 😴、`展覽` 🖼️、`購物` 🛍️。

**標準活動格式與所有可用欄位：**
```markdown
### 景點 | 濱海灣花園 Gardens by the Bay
time: 15:00            # 【必填】開始時間
endTime: 18:30         # 【選填】結束時間
nameEn: Gardens by the Bay # 【選填】英文名稱
description: 超級樹林光影秀... # 【選填】活動描述文字。==免費光影秀==，~~入場需憑票~~
hours: 05:00-02:00     # 【選填】營業時間
cost: SGD 14/人        # 【選填】花費/預算，會成為右下角標籤
ticket: 門票詳細說明   # 【選填】會在畫面上呈現橘色框的票務提醒區塊
meta: 光影秀18:45場次  # 【選填】補充資訊，會呈現黃色框
address: 18 Marina Gardens Dr... # 【選填】地址，附帶地址時介面上會出現「給司機看」按鈕
mapLink: https://maps... # 【選填】Google Map 導航網址，會出現「Google Map 導航」按鈕
notes: ⚠️ 提前網路訂票...\n第二行備註 # 【選填】個人筆記，會出現在活動底部。用 \n 換行
copyable: 訂票代號 ABC # 【選填】綠色框的文字，點擊後會直接複製 (適合放訂位代碼、確認碼)
docLink: https://...   # 【選填】顯示「📄 查看文件」按鈕，點擊後在新分頁開啟連結（適合放 Google Doc、訂位確認 PDF 等）
app: 國泰航空          # 【選填】顯示 App 導轉按鈕，支援：台鐵、高鐵、長榮航空、國泰航空、Agoda
imageUrl: https://...  # 【選填】活動圖片，點擊可放大（Lightbox）
imageUrl2: https://... # 【選填】第二張圖片，與 imageUrl 並排顯示
imageUrl3: https://... # 【選填】第三張圖片，三張時自動排列為「1大2小」版型
imageSize: small       # 【選填】單張圖片縮小顯示，預設為正常大小
cancelled: true        # 【取消功能】加上這行，此行程會反灰並畫刪除線
cancelReason: 行程太滿 # 【取消註解】在反灰的行程下顯示取消原因
```

### ✔️ 住宿特殊格式
若是住宿分類（`### 住宿 | XXX`），可用以下專用欄位（自動呈現為可摺疊收納的面板）：
```markdown
### 住宿 | Marina Bay Sands
checkIn: 15:00         # 入住時間
checkOut: 11:00        # 退房時間
price: SGD 450/晚      # 房價
nights: 2              # 入住幾晚
address: 10 Bayfront Ave, Singapore
notes: 提醒事項或確認碼
copyable: 確認碼 MBS20260501
```

## 3. 編輯「美食清單」 (Tab)
以 `## 美食清單` 為開頭，並使用 `###` 分配城市或地區分組：

```markdown
## 美食清單

### 新加坡（或第一區）
- 天天海南雞飯 | 必吃敘述文字 | SGD 5-8  # 格式必須是：- 餐廳名 | 敘述 | 價格
- 辣螃蟹 Chilli Crab | 推薦 Jumbo Seafood | SGD 80-100/2人

### 聖淘沙（或第二區）
- 環球影城餐廳 | 超貴 | SGD 30
```

## 7. 新增活動圖片

### 圖片放在哪裡？
每個行程資料夾下都有一個 `img/` 子資料夾，圖片統一放這裡：
```
2026_04_HK/
  ├── index.html
  └── img/
       ├── 普特曼酒店.jpg
       └── M+博物館.jpg
```
> 💡 **建議用英文或數字命名**，避免中文檔名在網址中變成亂碼（如 `%E6%99%AE...`）

---

### 取得圖片網址（兩種方式）

#### 方式一：自己組網址（最快）
只要知道檔名，照以下規律填入即可，**前綴永遠不變**：

```
https://raw.githubusercontent.com/YTLAnton/antonstrip/main/【資料夾名稱】/img/【檔名.jpg】
```

範例：
```
https://raw.githubusercontent.com/YTLAnton/antonstrip/main/2026_04_HK/img/Putman-Hotel.jpg
https://raw.githubusercontent.com/YTLAnton/antonstrip/main/2026_04_MO/img/grand-lisboa.jpg
```

#### 方式二：從 GitHub 網頁複製（最簡單）
1. 開啟 GitHub 網頁，進入 `img/` 資料夾，點進圖片檔案
2. 圖片出現後，在圖片上**按右鍵 → 「複製圖片網址」**（Chrome/Edge 皆支援）
3. 貼出來的網址長這樣，**可以直接使用**：
   ```
   https://github.com/YTLAnton/antonstrip/blob/main/2026_04_HK/img/Horlick(2025).JPG?raw=true
   ```
4. 注意：網址結尾必須有 `?raw=true`，如果貼出來沒有這個結尾（只有 `blob/main/...`），則無法顯示圖片

---

### 推上 GitHub 才會生效
圖片放進 `img/` 後，必須先推上 GitHub，網址才能存取：
```bash
git add .
git commit -m "add images"
git push
```
> ⚠️ 在推上去之前，用瀏覽器直接開啟 index.html 時圖片會顯示不出來，這是正常的。

---

### 填入 index.html
```markdown
### 景點 | 普特曼酒店
imageUrl: https://raw.githubusercontent.com/YTLAnton/antonstrip/main/2026_04_HK/img/Putman-Hotel.jpg
imageUrl2: https://raw.githubusercontent.com/YTLAnton/antonstrip/main/2026_04_HK/img/Putman-Lobby.jpg
imageUrl3: https://raw.githubusercontent.com/YTLAnton/antonstrip/main/2026_04_HK/img/Putman-Room.jpg
```
- 只有一張圖：只填 `imageUrl`
- 兩張圖：填 `imageUrl` + `imageUrl2`，自動並排
- 三張圖：填三個，自動排成「1大2小」版型

## 💡 新手防呆小訣竅

1. **不想顯示的欄位**：不要留空，直接將該屬性**整行刪除**即可，系統會自動適應隱藏它。
2. **快速新增**：遇到想加行程時，最快的方法是**直接複製一段既有的** `### 景點 | XXX` 區塊，貼上後再修改裡面的文字，保證不出錯！
3. **格式錯誤檢查**：如果畫面突然怪怪的，先檢查你的冒號 `:` 後方是不是少打了一個「半形空格」（正確範例 `time: 15:00`）。
